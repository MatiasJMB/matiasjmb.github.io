## Problem

The bootcamp asked for a digital wallet that was front-end only. With no server, the data has to be stored in the browser itself.

## Solution

- I built a digital wallet with HTML, CSS and JavaScript.
- I developed the interface with Bootstrap 5 and jQuery.
- I stored the data in localStorage.
- I published an online version.

## Outcome

Built as the front-end module assessment of a bootcamp. You can try it online with the demo account.
